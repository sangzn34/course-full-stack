1. Variable Scope — let · const · var

ลอง declare ตัวแปรใน block แล้วดูว่าตัวไหนหลุดออกมาข้างนอก

// pseudo-code

function demo() {
  if (true) {
    var a = 1;
    let b = 2;
    const c = 3;
  }
  // access จาก outer scope:
  console.log(a); // ?
  console.log(b); // ?
}
function scope (outer)
if-block scope (inner)
› กด "run demo" เพื่อดู
เห็นอะไร:
  • var a หลุดจาก block ขึ้นมาที่ function scope → access ได้จากข้างนอก
  • let b และ const c ติดอยู่ใน block scope → access จากข้างนอกไม่ได้ (ReferenceError)
  • นี่คือเหตุผลใหญ่ที่เลิกใช้ var ตั้งแต่ ES2015

5. Spread ... & Rest

กระจายของจาก array/object ออก — pattern ที่เจอทุกครั้งใน React state update

📦 Array spread

const a = [1, 2, 3];
const b = [...a, 4, 5];
a
1 2 3
b
— กด spread

📦 Object spread (right wins)

const base = { name: 'Latte', price: 65 };
const next = { ...base, price: 70 };
base
name: 'Latte' price: 65
next
— กด spread
React analogy: setState({ ...state, count: state.count + 1 }) — copy ทุก field เก่า, override ที่ต้องเปลี่ยน. ห้าม mutate state เดิม.

7. Arrow Function · this Binding

arrow ไม่มี this ของตัวเอง → ใช้ของ scope แม่ — แก้ปัญหา callback ที่ this หาย

❌ regular function
class Cart {
  items = [];
  add() {
    [1, 2].forEach(function(n) {
      this.items.push(n);
    });
  }
}
↓ this → undefined
✅ arrow function
class Cart {
  items = [];
  add() {
    [1, 2].forEach((n) => {
      this.items.push(n);
    });
  }
}
↓ this → Cart instance
📺 Cart instance (regular)
items = []
📺 Cart instance (arrow)
items = []
